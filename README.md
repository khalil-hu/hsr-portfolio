# 声之命途 · 扒带作品集

崩坏:星穹铁道风格的网页作品集。四位角色(砂金 / 长夜月 / 爻光 / 昔涟)对应四首扒带作品。

## 打开方式

双击 `index.html` 即可在浏览器中打开。无需安装任何环境。

## 更新内容(重要)

所有作品信息集中在一个文件里:[js/data.js](js/data.js)

修改步骤:
1. 用文本编辑器(推荐 VS Code)打开 `js/data.js`
2. 替换每首歌的占位信息:曲名、原唱、风格、BPM、调性、时长、音轨数、制作时间
3. 替换 `notes` 里的扒带手记(每个数组元素是一段)
4. 保存,刷新浏览器

## 放入视频

1. 把四首作品的视频文件复制到 [videos/](videos/) 文件夹
2. 文件名与 `js/data.js` 中的 `video` 路径保持一致:
   - `videos/01-shajin.mp4`(砂金)
   - `videos/02-changyeyue.mp4`(长夜月)
   - `videos/03-yaoguang.mp4`(爻光)
   - `videos/04-xilian.mp4`(昔涟)

放入前,页面会显示"视频待放入"提示;放入后刷新即可播放。

## 目录结构

```
hsr-portfolio/
├── index.html          主页面
├── css/
│   └── style.css       全部样式(设计系统)
├── js/
│   ├── data.js         作品数据(改这里)
│   └── main.js         交互引擎(一般不用改)
├── assets/
│   └── characters/
│       ├── *.png/jpg   原始素材(高清)
│       └── web/        网页压缩版
└── videos/             视频文件放这里
```
